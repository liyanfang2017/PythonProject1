# 用户登录模块 全套API接口正式文档（测试专用）

## 一、通用接口规范（所有接口统一约束）

1\. 所有请求统一请求头：Content\-Type: application/json
2\. 所有接口统一返回格式：code、msg、data
3\. 成功状态码：200
4\. 业务异常码：4xxxx 前端可提示；5xxxx 服务端异常
5\. 所有入参字段**不允许前后空格**，后端自动trim过滤
6\. 所有手机号、验证码、密码参数均做后端合法性校验，不依赖前端校验

## 二、密码登录接口

**接口地址**：POST /api/v1/user/login/password
**接口描述**：用户通过手机号\+密码方式登录系统

### 入参说明

|字段名|类型|是否必填|约束规则|
|---|---|---|---|
|mobile|string|是|11位纯数字中国大陆手机号，不能为空、不能含符号、字母|
|password|string|是|6\-20位，支持数字、字母、特殊符号，禁止纯数字|

### 成功响应示例（200）

```Plain Text
{
  "code": 200,
  "msg": "登录成功",
  "data": {
    "token": "字符串令牌，有效期2小时",
    "userId": "用户ID数字",
    "nickName": "用户昵称"
  }
}
```

### 业务错误码清单（重点用于异常测试用例）

- 40001：手机号格式不正确（非11位、含非法字符）

- 40002：密码错误

- 40003：手机号未注册，账号不存在

- 40004：账号已锁定（连续输错5次密码锁定30分钟）

- 40005：账号已注销，禁止登录

- 40010：密码长度不符合规则（小于6位或大于20位）

- 40011：密码为纯数字，不符合平台密码规则

## 三、获取短信验证码接口

**接口地址**：POST /api/v1/user/sms/send
**接口描述**：发送登录短信验证码

### 入参说明

|字段名|类型|是否必填|约束规则|
|---|---|---|---|
|mobile|string|是|11位合法手机号|

### 业务限制规则（测试重点边界）

- 60秒内同一手机号只能发送1次

- 单日同一手机号最多发送10次

- 未注册手机号不允许发送验证码

- 锁定状态账号禁止发送验证码

### 错误码

- 40006：请求过于频繁，60秒内禁止重发

- 40007：当日验证码发送次数已达上限

- 40012：手机号非法

- 40013：用户不存在/账号异常

## 四、短信验证码登录接口

**接口地址**：POST /api/v1/user/login/sms
**接口描述**：通过手机号\+短信验证码登录

### 入参说明

|字段名|类型|是否必填|约束规则|
|---|---|---|---|
|mobile|string|是|11位合法手机号|
|smsCode|string|是|固定6位数字，非空|

### 验证码规则

- 验证码有效时长：5分钟

- 验证码仅可使用一次，验证成功即失效

- 验证码错误3次，当日禁止验证码登录

### 错误码

- 40008：验证码错误

- 40009：验证码已过期

- 40014：验证码为空

- 40015：验证码错误次数过多，当日禁用

## 五、登录全局业务约束（用于测试用例全覆盖）

- 单点登录：同一账号仅支持一端在线，后登录挤掉前登录

- 所有登录失败行为均记录日志：IP、手机号、时间、错误原因

- 禁止明文传输密码、验证码

- 前端所有校验仅为辅助，后端必须二次强校验
